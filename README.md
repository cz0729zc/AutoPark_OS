### 🚗✨ **智能立体车库系统设计方案**

------

#### 🔍 **1. 系统概述**

本项目基于 **STM32 控制器** 开发智能立体车库系统，通过 **X/Y 轴电机** 控制载车板移动，实现 **4 车位立体停放**（坐标布局：上层【2,1】【2,2】，下层【1,1】【1,2】）。
 系统集成以下核心功能：
 🔐 **RFID 身份验证**、📈 **自动调度算法**、📍 **实时车位监控**、💰 **电子计费**，实现全流程无人化操作，提升停车效率与管理智能化水平。

------

#### 🧠 **2. 核心功能**

| 🧩 **功能模块**     | ⚙️ **实现方式**                                               |
| ------------------ | ------------------------------------------------------------ |
| 🚙 **自动存取车**   | - 用户刷卡（RFID）后按【存车键】- 系统查找空位（内存数组：0=空 / 1=占用）- X/Y 轴电机按最短路径调度（约 1 秒/车位），蜂鸣器短响提示 |
| 📊 **实时车位显示** | - LED 屏幕动态显示空位数量与位置（如【2,2】可用）- 每次存/取车后实时更新车位状态 |
| 💵 **自动计费**     | - 定时器统计停车时长（精确至秒）- 取车后自动计算费用，并通过短信发送账单📱- 超过 2 分钟未支付会自动通知管理员 ⚠️ |
| 🛡️ **安全监测**     | - 光电传感器检测载车板位置，实现防撞保护- 异常时立即停止电机并发出报警声 🚨 |

------

#### 🔄 **3. 工作流程**

##### ✅ **存车流程：**

1️⃣ 车主驶入底盘 → 下车刷卡 → 系统验证身份（RFID）
 2️⃣ 系统自动查询车位状态（优先顺序：【1,1】→【1,2】→【2,1】→【2,2】）
 3️⃣ 若【2,2】为空：
  ➡️ X 轴电机正转 2 秒（蜂鸣器滴滴）
  ➡️ Y 轴电机正转 2 秒（再次滴滴）
 4️⃣ 更新车位状态 → 启动定时器计费 ⏱️

##### 🚗 **取车流程：**

1️⃣ 刷卡识别 → 显示费用 → 用户确认支付
 2️⃣ X/Y 轴电机反转，载车板归位（蜂鸣器提示）
 3️⃣ 到达后蜂鸣器长响 4 秒，提示车主取车 📣
 4️⃣ 系统发送账单短信（包含停车时长与费用）📤

------

#### 🔧 **4. 硬件设计**

| 🔩 **组件**          | 🛠️ **作用**                                 |
| ------------------- | ------------------------------------------ |
| 🧠 STM32F103C8T6     | 主控芯片，负责所有逻辑控制与模块通信       |
| ⚙️ 步进电机（X/Y轴） | 控制载车板水平/垂直移动（1 秒/车位）       |
| 🪪 RFID 读卡器       | 身份认证，用于刷卡存取车                   |
| 📡 光电传感器        | 检测车板位置，防止越位、防撞保护           |
| 📲 GSM 短信模块      | 向用户/管理员发送账单或故障报警            |
| 🔊 蜂鸣器            | 操作音效提示（短响=移动中，长响=取车完成） |

------

#### 🛡️ **5. 安全与扩展**

- ⚠️ **异常处理**：电机卡顿或位置异常将触发急停机制，短信自动告警
- 🧱 **可扩展性**：支持增加 **Z 轴电机** 以拓展为多层停车（需调整坐标系统）
- 🌱 **节能模式**：系统无操作时自动进入低功耗待机状态
