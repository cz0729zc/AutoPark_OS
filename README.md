### **智能立体车库系统设计方案**

#### **1. 系统概述**  
本项目为基于 **STM32 控制器** 的智能立体车库系统，通过 **X/Y轴电机** 控制载车板移动，实现 **4车位立体停放**（坐标布局：上层【2,1】【2,2】、下层【1,1】【1,2】）。系统集成 **RFID身份验证**、**自动调度算法**、**实时车位监控** 和 **电子计费** 功能，实现全流程无人化操作。

---

#### **2. 核心功能**  
| **功能模块**        | **实现方式**                                                 |
| ------------------- | ------------------------------------------------------------ |
| **1. 自动存取车**   | - 用户刷卡（RFID）后按【存车键】，系统自动查询内存数组（0=空/1=占用）<br>- 按最短路径调度：X/Y轴电机协同移动（1秒/车位，蜂鸣器短响提示） |
| **2. 实时车位显示** | - LED屏幕动态显示空位数量及位置（如【2,2】可用）<br>- 存取车后立即更新状态数组 |
| **3. 自动计费**     | - 定时器统计停车时长（秒级精度）<br>- 取车时自动计算费用，短信推送账单至用户手机<br>- 超时2分钟未支付则通知管理员 |
| **4. 安全监测**     | - 光电传感器检测载车板位置，防撞保护<br>- 故障时立即停止电机并报警 |

---

#### **3. 工作流程**  
**存车流程:**  
1. 车主驶入底盘 → 下车刷卡 → 系统验证RFID  
2. 查询车位状态（优先检测【1,1】→【1,2】→【2,1】→【2,2】）  
3. 若【2,2】为空：  
   - X轴电机正转2秒（蜂鸣器滴2声）→ Y轴电机正转2秒（滴2声）  
4. 更新车位状态为占用，启动定时器计费  

**取车流程:**  
1. 刷卡识别 → 显示停车费 → 支付确认  
2. X/Y轴电机反转归位（蜂鸣器提示音）  
3. 载车板到达后，蜂鸣器长响4秒提醒取车  
4. 短信发送账单（含时长和费用）  

---

#### **4. 硬件设计**  
| **组件**          | **作用**                                 |
| ----------------- | ---------------------------------------- |
| STM32F103C8T6     | 主控制器，处理逻辑控制与通信             |
| 步进电机（X/Y轴） | 驱动载车板水平/垂直移动（1秒/车位速度）  |
| RFID读卡器        | 用户身份认证                             |
| 光电传感器        | 检测载车板位置，防止越界                 |
| GSM短信模块       | 向用户和管理员发送账单及警报             |
| 蜂鸣器            | 操作提示音（短滴=移动中，长响=取车完成） |

#### **5. 软件逻辑**  
```c
// 示例：车位状态数组（C语言）
uint8_t parking_map[2][2] = {
    {0, 0}, // [1,1], [1,2]
    {0, 0}  // [2,1], [2,2]
};

// 存车调度伪代码
void park_car() {
    for(int y=0; y<2; y++) {
        for(int x=0; x<2; x++) {
            if(parking_map[y][x] == 0) { // 找到空位
                move_x_axis(x+1);  // X轴移动x秒
                move_y_axis(y+1);  // Y轴移动y秒
                parking_map[y][x] = 1; // 标记占用
                start_timer();     // 开始计费
                return;
            }
        }
    }
}
```

---

#### **6. 安全与扩展**  
- **异常处理**：电机卡顿时触发急停，短信通知管理员  
- **扩展性**：可通过增加Z轴电机实现多层停车（需修改坐标算法）  
- **节能模式**：无操作时自动进入低功耗状态  

此设计平衡了成本与自动化需求，适合商场、小区等场景部署。
